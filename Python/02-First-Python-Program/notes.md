
# Python — Points to Remember

Python is free and open-source software. It can be downloaded from the official website:

https://www.python.org/

Python's source code is also available, allowing developers to study, modify, and use it according to the applicable license terms.

## Installing Python

- Visit the **Downloads** section of `python.org`.
- Select the required Python version.
- Choose the appropriate **32-bit or 64-bit** version according to your operating system.
- Python is available for Windows, Linux/UNIX, macOS, and other supported platforms.

## Important Python Packages

### NumPy
Used for numerical computing and working with arrays, including multidimensional arrays.

### Pandas
Used for data analysis and data manipulation.

### xlrd
Used to read data from supported Excel spreadsheet files.

### Matplotlib
Used to represent data using graphs, charts, and diagrams.

## Ways to Execute Python Programs

Python programs can be executed in three common ways:

1. Python Command Line / Interactive Shell
2. Python IDLE
3. System Prompt / Terminal

## Python File Extension

Python source files are saved with the `.py` extension.

Example:

```text
first.py

Python Help

Python provides a built-in help system.

At the Python prompt, use:

>>> help()

This enters Python's help mode.

To exit help mode, press Enter at the help prompt or type:

quit

You can also get help about a specific function:

>>> help(print)

Python Documentation in IDLE

In IDLE, select:

Help → Python Docs

This provides detailed documentation about Python features.
